Browser edition of [GoldenHour](https://github.com/sgoel2718/goldenhour). The contraction hierarchy is
preprocessed by the Java core; routing, dispatch and the live fleet simulation run in your browser.
Click the map to report an emergency, or open **Routing lab** to race Dijkstra, A*, bidirectional
Dijkstra and contraction hierarchies on the same query.
